# claude-projects

A collection of Claude-assisted experiments and projects. Each one lives in its own subfolder and is viewable directly on GitHub Pages.

## Projects

- [portfolio](portfolio/) — personal design portfolio site. Live at [lisalucyliu.github.io/claude-projects/portfolio/](https://lisalucyliu.github.io/claude-projects/portfolio/)
- [data-grants-prototype](data-grants-prototype/) — functional AWS Data Exchange "data grants" prototype (sent + received homepages), restyled from original wireframes using the current Cloudscape Design System. Live at [lisalucyliu.github.io/claude-projects/data-grants-prototype/](https://lisalucyliu.github.io/claude-projects/data-grants-prototype/)
- [private-marketplace-prototype](private-marketplace-prototype/) — clickable AWS Private Marketplace admin prototype built from Figma wireframes ("FINAL PMP" flows), following Cloudscape Design System guidelines. Core admin loop: Dashboard → Organizational structure → Experiences → 5-step Create experience wizard. Live at [lisalucyliu.github.io/claude-projects/private-marketplace-prototype/](https://lisalucyliu.github.io/claude-projects/private-marketplace-prototype/)
